1. 训练中仅78帧开发集用于模型选择；不建立heldout数据库或测试loader。
2. 完成训练后核查生产者退出记录、CUDA设备、预算、实际更新及开发曲线，冻结唯一候选checkpoint的SHA。

4. 53保留帧中46帧有历史评估记录，只能作为固定留出对照，不能称为全新盲测，也不得用于反复挑epoch、调参或补训练样本。另7帧来源及隔离继续保留。

本次执行提案仅包含试训，尚不包含后续GPU评估授权或DFT优化预算。力准确度改善之后，再制定独立C₂/C₃优化与成本对照，才能判断实际加速。force-only方案不能证明吸附能预测精度改善。C₃H₂O训练中仍缺≤0.05eV/Å帧，优化末段能力须保留未验证结论。
