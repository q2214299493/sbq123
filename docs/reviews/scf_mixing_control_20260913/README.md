## 获批后如何判定

1. **先看运行证据**：确认唯一作业/唯一写入目录、MPI启动、实际输入与绑定一致。若仍见空字节或不一致读数，先复核节点与共享存储视图；未解决前不把输出当成可靠标签。
2. **看SCF趋势**：按同编号电子步比较能量变化、电子残差、密度残差和非厄米警告。前几步暂时振荡不直接判失败，不另设自动停止的硬阈值。
3. **完成条件不放宽**：EDIFF=1e-7真实满足且正常终止；达到NELM=200但未满足EDIFF属于未收敛。NSW=0不涉及离子优化收敛。
4. **核对解的可重复性**：比较9752745的总能、逐原子力、总/局部磁矩和几何，而非仅“程序结束”。显著不一致必须审阅，不能自动当作同一磁性解或更优物理解。
5. **保存态可用性**：WAVECAR/CHGCAR完整、非空、格式与输入兼容并记录哈希。冷启动对照通过后，再单独准备冻结几何的读取重启态验证；本方案不自动提交它。
6. 若仍发散，保留失败证据，判断是幅度假设不足还是运行/输出异常；不得原样重投，也不自动追加近线性混合、结构松弛或Dimer。
