# 有限计数单元的独立参考

一个 `oxide-counting-cell` 有 4 个 acid-A、3 个 oxygen-B。已有观测给出 2 个桥式 CO₂。以下将该观测作为候选测试初态，仅使用计数；没有从晶胞面积推算密度，也没有假设实际进料或解离。令 n 为单元内桥式分子数，从该状态发生带符号的 ξ 个净吸附事件后 n = 2 + ξ。仅由库存给出的界限为 −2 ≤ ξ ≤ 1，实际可用相邻位点对还取决于几何。[原观测](../stage_b2_1/oxide_observations.json) · [机器可读参考](independent_reference.json)

| 独立库存 | 容量 | 初始已占 / 空位 | 占用 / 空位分数 | 每净吸附一分子的占用 / 空位分数变化 |
| --- | ---: | --- | --- | --- |
| acid-A | 4 | 2 / 2 | 1/2、1/2 | +1/4、−1/4 |
| oxygen-B | 3 | 2 / 1 | 2/3、1/3 | +1/3、−1/3 |

同一分子变量满足 4 θ_A = 3 θ_B = n，且每套库存 θ + v = 1。逐事件的元素 C、O、净电荷以及两个库存的“占用加空位”残差均精确为零。单元中有两份分子计数与四份位点占用，分别用于不同守恒量。

**速率和源项。** 令 J 为已转换至每计数单元每秒的净事件数。气相 CO₂ 和桥式 CO₂ 的反应源项分别为 −J 和 +J，两套库存各自的空位源项均为 −J，占用源项均为 +J。相应的空位分数导数为 −J/4、−J/3。在维持气相压力的模型中气相反应源项依然存在，储库可补偿其变化。实际 J 及所有依赖它的初态数值源项均为 null。B.1 源项投影已按正事件、逆事件、零与未知分别复核。

**定量参考的条件。** 若研究者选择独立空位的均场质量作用律，两套独立库存的空位分数乘积在候选初态是 1/6。这个乘积不是可配对酸氧邻居的实测比例。还须声明气体活度 a_g、桥式分子的共同活度 a_b(n)、参考分母、位点对可及性和速率系数。如果所选模型采用无量纲活度，且两个系数均已换算到同一计数单元，可写作

```text
J+(n) = k+ a_g (1 − n/4) (1 − n/3)
J−(n) = k− a_b(n)
J(2)  = k+ a_g / 6 − k− a_b(2)
```

手册给出气体标准压力 p° = 0.1 MPa = 1 bar；对理想气体约定可写 a_g = p_CO₂/p°。若直接以 bar 计分压进入速率式，正向系数须显式含 bar⁻¹。方程样稿的静态核对确认一个桥式 CO₂ token、一个桥式分子变量、两个耗用空位，及两套初始空位分数；能量字段、工况和桥式变量数值仍待绑定。[厂商手册 §4.3](https://www.catkinas.com/category/manual/)具体的 k+、k−、温度、CO₂ 分压、热力学平衡常数及速率分母均无本例依据。若强行将共同变量 Q 同时当作两套库存的占用分数，初态将同时要求 Q = 1/2 和 Q = 2/3。这是本例可直接检出错误归一化的判据。需要明确从 Q1x2_CO2 到唯一分子数 n 的换算，再由 n/4 和 n/3 计算两侧覆盖度。

在冻结气相的单一可逆交换中，稳态要求 J+ = J−，且 0 ≤ n ≤ 3。所需的稳态残差目标是零，已计算稳态分子数、实际数值残差以及原生比较值均为 null。只有在活度标准态相同、构型因子已按同一约定计入后，才能将 k+/k− 与独立给出的 K°（或由 ΔG°、T 得出的 K°）比较。在二维库存约束下方程自洽和元素守恒可以先验验证；数值详细平衡还缺独立热力学依据。
