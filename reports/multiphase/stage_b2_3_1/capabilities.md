# CATKINAS 原生能力矩阵

证据来自 20261106 分发包在 MATLAB R2025b 上的实际执行，程序自报版本为 20230524。Ni/Cu 四步合成基准的原生输入、两份独立 MAT 输出和 V2 重放见[机器回执](validation.json)。早期过期构建、随附示例、孤立单步和闭合模型各有各的证据范围。

| 问题 | 结论 | 验证边界和映射动作 |
| --- | --- | --- |
| A. 多催化相 | 受限支持 | Ni 和 Cu 的两个表面库存可在均场模型中分别编号。相、表面及声明的接触身份保存在随附清单。空间几何、相分数及多个独立接触的耦合未验证。 |
| B. 多位点库存 | 受限支持 | 原生输入和输出均区分 `#1`、`#2`。每参考对各一份，每个库存独立守恒。更多库存或不等容量需要独立证据。 |
| C. 跨库存分子吸附 | 一个分子跨库占位目前不支持 | 经求解的解离步骤产生两个 H 单齿驻留物种。氧化物 fixture 中一个 CO₂ 同时占 acid-A 和 oxygen-B，当前适配器没有保留这一分子计数的原生标记，返回物种 ID 和完整足迹。 |
| D. 相间转移 | 受限支持 | 已执行 `H#2 + #1 <-> H#1 + #2`。网络保留来源、去向与相反的空位变化。历史记录将它归类为 diffusion。B.2.2.2 显式转移 fixture 匹配该单步形状，但缺闭合周转和速率，其独立工况引用也未绑定到原生点。 |
| E. 跨相基元反应 | 已验形式受限支持，任意形式未验证 | 基准中跨两个库存的解离已有原生结果。任意双表面反应物结合、额外旁观位点或不同连通图须单独核验。多个步骤分别能读入，只能支持各自的语法。 |
| F. 界面专属产物 | 未验证 | 当前没有接触专属物种和私有位点的原生身份回读。通用网络保留 junction 和产物身份。 |
| G. 产物落在第三相 | 未验证 | 三相 fixture 保留 face-C、C-pool 和 triple-junction。缺原生第三库存与三相耦合的验证。 |
| H. 可逆及显式不可逆 | 可逆语法已支持，显式单向目前不支持 | 四条 `<->` 方程均回读过两侧速率。当前适配器缺经证实的单向编码，显式不可逆反应返回其 reaction ID。 |
| I. 可逆性未知或缺动力学参数 | 输入证据缺失，阻断 | 已识别的方程形式仍可报告；未知方向、缺失参数及未通过审核的参数分别保留，无法生成合格原生点。 |

支持指已有本机原生证据；受限支持指满足表内条件的表达能力。不支持描述当前适配器，未验证描述尚无充分原生证据。每个新项目仍须独立完成科学资格和执行审批。

同一解离方程单独运行时，CATKINAS 回显了方程及两个位点，随后在构建稳态速率方程时退出 1，未产生 MAT。厂商合成氨对照与 Ni/Cu 闭合基准各自成功运行。三个结果分别回答了解析、环境和目标网络是否可求解的问题。[孤立单步原生回执](../phase2_5_1/catkinas_target_attempt.json) · [随附示例对照](../phase2_5_1/catkinas_environment_control.json) · [闭合周转回执](../phase2_5_2/catkinas_closed_cycle_validation.json)
