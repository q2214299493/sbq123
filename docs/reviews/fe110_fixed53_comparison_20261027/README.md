## 对照口径与来源

误差是相对于已审核DFT单点标签的力误差，单位eV/Å。主指标为按原子汇总的向量RMSE：`sqrt(mean_atoms(sum_xyz((F_model-F_DFT)^2)))`，不除以3。另保存分量MAE、向量MAE、P95、最大误差和方向统计。固定Fe原子0–17排除；可动Fe为其余27个Fe。固定原子的原始预测保留，没有将约束清零后的力与DFT比较。

53帧分为46个历史已评估帧（两个VASP作业，各23帧）和7个REICO保留帧（四个family）；**不是53个全新独立盲测，也不是53个独立轨迹。** 候选权重在本次预测前冻结，使用既有开发集选出的唯一候选，不按这些误差重新选模或补训练数据。原始基底预训练数据与当前体系的重叠未知。
