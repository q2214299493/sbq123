# Phase 3.2.0 首组过渡态扰动验收

在 400 K 的合成 Ni/Cu 四步闭环中，位点间氢转移步骤 `transfer` 的中心差分 DRC 为 **0.04113190545**。该值仅适用于本次给定温度、分压和净周转定义。四步反应全部保留，两次原生运行分别通过原有的单点审批、收敛及科学验证。[机器可读结果](result.json) · [逐步系数与通量对照](comparison.md)

## 基线与扰动

选择转移步的依据是两个方向均有已评审的活化自由能和相同口径的前因子。转移在 Cu-bridge 与 Ni-top 两个库存之间进行，不涉及气体的标准态换算，可直接比较位点再分配。该选择未预设它是控速步骤。

复用 Phase 3.0 已接受的 `run`。从开发目录原始归档重新验证了执行与批准回执、批准来源哈希、模型与配置、MAT、日志、输入回显、收敛状态，并复现 Phase 3.1 已接受的动力学分析。原基线结果 SHA-256 为 `6c09b2d304b0829e8912baa670fd274425c4e49a0376f4a4e710db981e4692f7`，父数据集版本为 `417cf1dc3236175476441c4c4e7b4bd5771bc4a7062aa5e34eff69070483d11b`。原始基线仅作读取。

## 敏感性与科学验证

以能量升高为正号，δ = 0.01 eV，kBT = 0.03446933305 eV。按 −kBT [ln(r₊) − ln(r₋)]/(2δ) 求得无量纲 DRC。另一条计算从原生 MAT 的 HNO 净生成速率出发，除以总反应的 HNO 化学计量数 2，再计算对数速率比，复现同一数值。报告保留导数符号，结果允许超出 0 到 1。

提高转移势垒后，转移的正、逆系数均降低，Cu-bridge 上的氢积累，Ni-top 上的氢减少，净周转下降 1.358%。降低势垒后净周转增加 1.025%。两个单侧差分分别为 0.04712913 和 0.03513468，显示该步长两侧响应并不对称。此处只测得有限扰动下的局部敏感性，尚无步长收敛证据或全部反应的 DRC 排名。

三个状态的 H、N、O 净元素残差及两个位点库存残差均为零。最大表面稳态残差为 5.68×10⁻¹⁴。对全部四步的原生方向系数做标准态换算后，详细平衡对数残差的最大绝对值为 3.35×10⁻⁶ 以下，满足原有 10⁻⁴ 容差。模型中两侧位移引起的转移反应自由能变化为零。

## 软件、预算及复现

新增 `baseline_mkm.ts_perturbation`、`drc_pair`、`drc_report` 和版本化 JSON Schema。单点准备和离线分析共用从父模型重建衍生数据集的核对。执行仍由原有单点工作流启动 CATKINAS，本轮任务附件作为这两次限定运行的授权来源。每个决定分别绑定了相应运行计划哈希，未沿用基线的执行批准。

正、负扰动顺序运行，实际执行预算计时为 **197.83 / 480 秒**，余 **282.17 秒**，无重试。计时覆盖第一例执行前至第二例结果复验后，准备输入与人工决策等待在预算外。每次原生调用上限为 210 秒，剩余总预算更小时取其值。保留逐次回执和原始日志。对已完成目录重复调用并拦截任何新启动，验证了复用路径。

发布的两份 MAT、日志摘录和接受回执支持离线回放。从父参数重建两个衍生版本，解析原生输出并复验科学合同，可逐字节重建两份规范化结果的 SHA-256。[正扰动回执](plus/accepted.json) · [负扰动回执](minus/accepted.json) · [使用说明](../../../modules/baseline_mkm/README.md)
