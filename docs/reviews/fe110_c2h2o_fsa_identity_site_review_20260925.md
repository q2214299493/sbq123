## 对首版动力学模型的影响

1. 可核对的表面连接关系是 `H–C45–C46–O47–H`，即一个 H 在 C、一个在 O 的 C₂H₂O*。它**不是**两个 H 都在 C 且 O 不带 H 的气相酮烯 `CH₂=C=O` 连接关系。吸附态键级、可脱附异构体及其气相名称仍需独立核对，不能仅凭分子式同为 C₂H₂O 就建立脱附反应。
2. 最终吸附主要通过两个相邻 C 中心与两个 hollow 区域接触。几何上共涉及四个不同的近邻表面 Fe，但**Fe 接触数不等于 MKM 位点化学计量**。单 `*`、相邻双位 `**` 或显式 ensemble 的选择尚未批准；先保留独立物种/位点标签，避免错误的位点守恒。
3. 对已接受的 MID→FS-A O–H 成键步骤，原子数守恒是清楚的；MKM 中的空位计数与气相产物释放仍不能据此推定。首版可先定义经验证的表面形成通量目标，不宣称已具备气相酮烯 TOF。
