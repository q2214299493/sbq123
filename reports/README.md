# Reports

Create a report only when the user explicitly requests a saved report/document or when a reviewed scientific result needs a durable deliverable. Routine progress remains in chat and the compact current-state snapshot.

Use:

```text
YYYY-MM-DD_short-topic.md
```

Each report should contain only:

- check time and task
- local and remote source paths
- commands or scripts used
- verified status and key measurements
- interpretation separated into electronic, force, and geometry findings
- unresolved issues and next action

Do not paste entire OUTCAR or OSZICAR files. Link or index the relevant raw files instead.
