control 总体向量 RMSE 比原始模型降低约 4.55%，但 C₂ 合并 RMSE 基本未改善，0002 与 0004 的误差略增，O 组也未改善。原始模型对这些高受力起点本就较准确；本次结果不支持“微调带来明显额外加速”的结论。

DFT 吸附原子力幅值为约 0.395–21.624 eV/Å。control 的整体误差/DFT 力 L2 比为 4.41%，逐构型为 1.90%–13.16%；不能用最高受力构型对整体相对误差的主导效应掩盖最差构型。0004 的一个 C 原子 DFT 力仅 0.877 eV/Å，control 方向偏差约 45.73°，是当前最突出的方向问题。

可动 Fe 的误差单独报告，其平均方向余弦为约 0.509/0.534；小力方向不能由吸附原子的总体好结果代替验证。当前吸附原子最小力仍有约 0.395 eV/Å，本轮没有接近最低点的准确性证据。
