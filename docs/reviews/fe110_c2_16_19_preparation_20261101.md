# Fe(110) rows16–19: exploratory structure preparation

The user requested the same adsorption workflow for four explicit molecular
graphs, with at least three candidates per graph. This step prepares review
artifacts only; it does not authorize or execute GPU inference or VASP.

- 16: C2H4O, CH3-[C]-OH, CARE prefixJVKQHDUTAFISFX.
- 17: C2H4O, [CH2]-CH2-[O], prefixODVIVHCWPDKHAQ.
- 18: C2H4O, [CH]-O-CH3, prefixQJVFBSULGFNYKF.
- 19: C2H6, CH3-CH3, prefixOTMSDBZUPAUEDD.

The geometry helpers preserve the accepted Fe45 slab, cell, Fe positions and
bottom18-Fe fixed mask. Row17 reuses the prior three candidate POSCARs byte for
byte. Other rows use graph-checked local CARE molecular geometry and explicitly
exploratory placement. Ethane stays molecular in its three starting approaches;
the source Fe48 slab, source energies and source magnetic state are not copied.

The scoped whitelist queries found no usable exact motif records. Controlled
primary-literature screening did not recover three ranked stable Fe(110)
coordinates for each requested graph. These are therefore starting hypotheses,
not literature-proven minima. The failed/borderline local preparation attempts
and the provisional v1 package are retained. The active coordinates are v2.

The source adapter is `archive/fe110_c2_16_19_prepare_20261101/`:

1. `prepare.py`: creates a new twelve-seed review version, refusing overwrites.
2. `verify.py`: independently checks saved graphs, explicit periodic distances,
   slab identity, fixed masks and byte-exact row17 reuse.
3. `test_prepare.py`: targeted normal and negative tests; these tests require
   the private local geometry inputs and generated candidate fixtures.
4. `render_review.py`: renders the verified coordinates with explicit view
   labels and creates a review bundle without changing coordinates.

Scientific boundaries remain unchanged: initial-seed inequivalence does not
prove distinct optimized minima; the three C2H4O graphs cannot be interchanged.
The seven/eight-adsorbate-atom cases exceed the documented old AQCat near-minimum
domain, so model predictions require an explicit domain/review caveat and cannot
be treated as calibrated energies or uncertainty. No new gas reference,
dispersion correction, training, model promotion or database result is created.

Private calculation inputs, coordinates, images, evidence JSON, CARE source,
registry and review archives remain local under
`calculations/fe110_c2_adsorption_16_19_20261101/`; they are not part of the source
release. Structure review precedes separately authorized GPU work and its
subsequent work-side scientific review before any DFT submission.
