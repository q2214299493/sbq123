## 4∶3 库存的可检验关系

令 `n` 为每个 `oxide-counting-cell` 的桥式 CO₂ 分子数。每个分子占用一个 acid-A 和一个 oxygen-B。库存容量及两个分子的快照来自 B.2.1 的计数观察；结构 fixture 单独提供物种、位点和足迹。此计数单元尚无物理晶胞体积、位点密度或邻接图的绑定。[计数观察](../stage_b2_1/oxide_observations.json) · [结构 fixture](../../../tests/fixtures/multiphase/synthetic_oxide_site_network.json)

| 每计数单元 | 容量 | 被占位数 | 空位数 | n = 2 的占位分数 | n = 2 的空位分数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| acid-A | 4 | n | 4 − n | 1/2 | 1/2 |
| oxygen-B | 3 | n | 3 − n | 2/3 | 1/3 |

两个库存各自守恒，且共享同一个分子数。以 `vA`、`vB` 表示各自的空位分数，则 **4(1 − vA) = 3(1 − vB) = n**。一次净吸附使每套库存各减少一个空位，对应空位分数分别变化 −1/4 和 −1/3。容量只给出 n ≤ 3 的上界；允许同时形成多少桥还取决于哪些位点可配对。

若厂商把 Q 定义为按一个固定分母 D 计的分子覆盖度，即 Q = n/D，则两条守恒式须满足

```text
vA + (D/4) Q = 1
vB + (D/3) Q = 1
```

这些方程是项目用来检查原生实现的必要关系。以下 Q 值均为同一快照在各个**假设分母**下的表示，没有一项被指认为原生 Q。

| 假设的分母 D | n = 2 时的 Q |
| --- | ---: |
| 4 个酸位 | 1/2 |
| 3 个氧位 | 2/3 |
| 7 个物理位点合计 | 2/7 个分子/位点；按被占位置计则为 4/7，前者数分子，后者数被占位置 |
| 1 个已声明计数单元 | 2 个分子/单元 |
| P 个合格酸–氧位点对 | 2/P；P 与允许的配对规则未知 |

若原生采用固定系数 α、β，正确的容量加权要求 **4α = 3β = D**。两条方程都使用单位系数会在任何非零桥式种群下与 4∶3 库存冲突。若原生输出 Q 和两套独立读出的空位分数，可在有已知计数的非零状态分别求 4(1 − vA)/Q 和 3(1 − vB)/Q，再核对它们在不同状态是否给出同一分母。仅检查空表面、等容量模型、两个从同一假设生成的空位值或单一求解残差，均无法区分这些分母。若厂商定义的是构型或配对概率，则需按其定义核对，固定 D 的假设不能直接套用。两个边际空位分数的乘积 1/6 只有在独立性假设下才是联合概率，不能据此得到可用相邻对数。
