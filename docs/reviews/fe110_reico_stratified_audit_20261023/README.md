# Fe(110) 训练轨迹的组成、连接和配位分层审计

2026-10-23。**已完成1597个训练帧的分层统计，发现原几何选点遗漏的连接/配位类型。原292个选点和冻结分区没有改变；没有新增DFT、模型推理、训练或恢复搁置的两项C₃任务。**

## 核心结果

各组成只与本组成的训练参考帧比较。下表的“已覆盖”表示至少有一个原选点落入该几何类型，并不表示该类型的力、能量或所有内部变化均已学好。

| 组成 | 训练池帧数 | 原训练选点 | 连接图：已覆盖/总数 | Fe配位分布：已覆盖/总数 | 连接图＋配位：已覆盖/总数 |
|---|---:|---:|---:|---:|---:|
| C₂HO | 252 | 36 | 13/14 | 24/33 | 31/53 |
| C₂H₂O | 317 | 46 | 29/35 | 31/37 | 43/71 |
| C₂H₃ | 252 | 36 | 13/15 | 23/32 | 34/74 |
| C₃H₂O | 776 | 115 | 56/70 | 74/109 | 106/203 |

主截断设置下，原选点没有代表的连接图共23类，连接图＋Fe配位组合共187类，涉及训练池488帧。每个遗漏组合保存一个诊断代表；**187不等于187种稳定化学物种，也不等于需要新增187个DFT。**

这187个代表中有71个与本组成原选点的几何RMSD小于0.10 Å（C₂HO10个、C₂H₂O6个、C₂H₃10个、C₃H₂O45个）。它们仍保留在诊断目录中，没有因为几何接近而删除。是否包含重要的力差异，要等相应DFT标签及磁性质控后判断。

按组成独立校准SOAP后，超出内部阈值的仅1帧：C₂HO的`family_0013_step016`，比值1.020943；其他三种组成均为0。**SOAP相近与离散连接/配位类型已经代表，是两种不同的判断。** 本次不能沿用“SOAP覆盖较完整”推断化学环境已经覆盖充分。分组后阈值也发生变化，不能把前后超阈值帧数直接解读为模型精度改善。

## 方法与边界

- 输入沿用前次审计的训练分区：1597帧、79个完整轨迹家族，对照233个已选训练帧。原开发集和最终测试集不参与描述符校准、环境类型统计或选点排序。
- 复用前次1597份544维SOAP缓存，校验结构哈希、中心索引、维数、有限值及归一化；本轮主分析不重算SOAP。C/O/H全部作为中心，Fe中心仍是距吸附原子3 Å内的可动Fe。
- SOAP的最近邻和阈值在每种组成内按元素分别计算。阈值仍取排除同家族参考后的p95，并保存p90/p99；这是内部诊断设置，不是论文阈值、力误差标定或精度保证。
- 分子内部连接复用`adsmind_lite.relaxed_analysis.connectivity_edges`及`configs/adsmind_lite/analysis_rules.yaml`：距离介于0.35 Å与1.25倍共价半径和之间记一条几何边。统计C–C、C–O、C–H、O–H等所有实际出现的边；不赋予键级或稳定分子名称。
- Fe配位同样使用这一半径几何规则，逐个吸附原子统计45个Fe邻居，再按C/O/H分别汇总。主设置的Fe–C/O/H截断分别为2.600/2.475/2.0375 Å。它们是本次诊断邻接定义，不是经DFT电子结构验证的成键阈值。
- 精确枚举至多6个吸附原子中同元素置换，构造与原子编号无关的连接图。联合类型同时保留“哪一个C/O/H有几个Fe邻居”，不会把相同配位直方图、但配位原子不同的环境强行合并。
- 逐帧几何事件与该家族的原始step0比较。随机起点本来就可能有多个片段；`association/dissociation`在这里仅表示这个距离图的片段数变化，不能直接认定发生了真实反应。

## 8个优先检查的例子

每种组成列2个不同训练家族的例子，按遗漏联合类型涉及的家族数、帧数，再按SOAP距离排序。这个规则便于先检查重复出现的缺口，不是DFT最优选点算法。

| 组成 | 例子 | 与原选点最近RMSD / Å |
|---|---|---:|
| C₂HO | family_0013_step016 | 0.139721 |
| C₂HO | family_0017_step014 | 0.152170 |
| C₂H₂O | family_0063_step014 | 0.144424 |
| C₂H₂O | family_0050_step005 | 0.145136 |
| C₂H₃ | family_0035_step015 | 0.167401 |
| C₂H₃ | family_0019_step015 | 0.138092 |
| C₃H₂O | family_0086_step014 | 0.151195 |
| C₃H₂O | family_0098_step016 | 0.122859 |

这8个例子通过与513份保留集几何的0.20 Å隔离检查；没有使用保留集的力、能量或模型误差。其余诊断代表尚未逐一做此隔离检查，不能称为DFT就绪输入。8例的三种截断逐点复核见`priority_sensitivity.json`；截断稳健也不等于重要的DFT力缺口。

逐点复核结果：只有C₃H₂O的`family_0086_step014`在三种截断下，其联合类型都未被原选点代表；其余7例的“遗漏”判断会随截断变化。这只覆盖这8个例子，不能外推为其他179个代表都不重要，也不能据此要求新增DFT。
