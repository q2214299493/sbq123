# Fe(110) 随机采样与能量–力训练小试方案

日期：2026-10-21。状态：**方案准备完成；不可执行，尚未生成结构、运行模型、提交DFT或训练。**

用户确认：第一版只覆盖当前Fe(110)吸附体系；按约300个去重后构型准备小试方案；观察到较好的C₂/C₃加速效果后，再讨论扩大到上千个构型。数量指原子构型，不是独立化学物种。

本目录是人工可审核的研究方案。`pilot_spec.json` 是本方案自有的数据描述，不是现有CLI支持的执行配置，不产生任何计算授权。`source_inventory.json` 记录本次读取的本地来源及原始字节SHA256；科学输入仍属于主工作区，不随发布分支复制。

## 目标与方法

验证新增随机离平衡构型是否改善当前Fe(110)上C₂/C₃吸附优化的可靠性与实际DFT成本。采用REICO的随机生成、优化轨迹采样、多样性选择思想，在当前固定Fe45基底约束下改造；不宣称复现原文的Ag–Pd–C–H–O广域势，也不承诺TS、其他晶面、氧化物或碳化物能力。

原文与代码：

- https://doi.org/10.1038/s41929-025-01398-3
- https://itcc.nju.edu.cn/dqxie/article/34.pdf （方法，期刊900–901页）
- https://github.com/HuGroup-shanghaiTech/REICO

训练标签是选定固定构型的DFT单点总能量和逐原子力。要求电子SCF收敛，不要求每个训练构型离子收敛。稳定吸附终态、最终吸附能和加速比较仍须单独通过现有科学审核。

## 筛选、去重与数据隔离

1. 优先剔除非有限数、身份/固定层/晶胞变化、原子碰撞、严重PBC错误等无效快照；SCF失败不能写为成功标签。
2. 在C₂/C₃、组成和优化阶段内进行多样性筛选，优先检验SOAP/局部环境描述符的距离选择；库、版本和覆盖统计须实测。不能把词法、简单位点计数或同模型重复输出称为语义覆盖或不确定度。
3. 几何复核必须保留相对表面的高度、位点、取向与上层Fe形变，只允许真实Fe(110)表面对称、平面PBC和合理同元素等价映射。不得直接复用会去掉整体位置/转动的分子Kabsch去重，或用ML能量筛掉新环境。
4. 先冻结轨迹家族分区，再选择快照；交叉近重复只剔除/隔离，不把测试家族改作训练。现有池的几何等价实现与阈值只能作为审核起点，不是物理稳定门槛。
5. 原始池、选中池、重复代表、拒绝项和原因全部保留；每个构型绑定生成参数、随机种子、父轨迹、帧号、元素顺序、约束及哈希，支持从未完成步骤恢复，不默认重提失败计算。

## DFT与磁性标签

- 使用现有PBE/PAW-PBE/ENCUT400/Fe45/Gamma5×5×1/ISPIN2/ISMEAR1/SIGMA0.20兼容分支；训练能量目标沿用与力匹配的TOTEN约定，不混入E0或文献能量。
- 单点标签由既有VASP输入与提交所有者生成并审核；要求固定构型、完整能量和全部原子力、SCF正常收敛、总磁矩和原子分辨磁矩。NSW=0及磁矩输出设置须在新输入包中显式审核，不套用不兼容的SIGMA0.10静态模板。
- 先利用首6个标签确认能量—力—坐标对应、SCF成功率、磁性可复现性及单例成本，再决定剩余批次。电子收敛不证明磁性基态；同一几何出现竞争亚稳磁解时隔离审核，不将其直接混成几何单值标签，不自动追加昂贵多初态计算。
- 当前NequIP训练标签审核及新模型后端绑定尚不存在。现有AQCat25/MatRIS微调权限不能被解释为已允许NequIP新模型训练；必须建立独立的环境、资源、哈希及运行范围绑定。
- VASP只在`sunboquan-codex`运行；GPU结果先返回work审核。可执行包另行审定，无直接GPU到VASP自动传递或自动提交。

## 训练对照：评价新增随机数据是否有用

固定一个小型NequIP保守能量–力架构，满足F=−∂E/∂R；当前只训力的AQCat25包不被就地改写。

- A：经重新审核的既有训练数据，联合训练能量和力。
- B：同一既有数据＋最多240个新训练构型；与A使用同一初始权重、相同模型/优化器/随机种子/实际更新预算和共同开发集。
- 共同开发集由既有60帧与最多30个新开发构型组成；原始数据版本与新标签分别保留来源。能量归一化和元素能量基准只由训练数据/审核参考确定，不读取最终测试标签做统计。
- 不同组成不能直接按裸总能量排序。重点审核同组成位点能差，并在裸表面/吸附物参考完整且兼容后评价吸附能；未达到结构优化收敛的训练帧不能作为平衡吸附能终态。
- 开发集选择冻结候选，最多30个新测试构型在候选冻结后统一评估。该测试是轨迹隔离的同域评估，不是无限制新物种外推。该最小对照衡量新增数据包的综合作用，不分别归因随机化、C₃覆盖和采样分布。

## 加速验收与上千构型扩容条件

先通过静态能量/力、有限差分一致性、连接/接触和从独立种子优化的几何审核，再准备配对VASP性能试验。建议最小4个种子（C₂、C₃各2）；每种子比较直接DFT、原模型预优化＋DFT、新模型预优化＋DFT三条路线，最多12个松弛任务，属于后续独立预算。只有精确相同种子、参数、资源且最终到达同一审核最低能盆的既有计算可替代其中的直接DFT对照。

**必须条件：**正常结束、电子/离子收敛、化学身份及位点符合目标、同盆地与能量兼容；失败或不同盆地单列，不能算加速比。若DFT本身发生真实重排，按实际身份审查，不能只把ML结构变化认定为模型错误。

**建议的“值得扩容”工作判据，尚未作为执行门生效：**C₂和C₃分别汇总的配对VASP CPU核时均下降至少20%，没有新增科学失败或实质能量/几何退化；同时报告离子步、SCF工作量、VASP墙时、GPU推理/采样/训练小时、300点标注CPU核时、全额小试成本和按预先声明未来任务数摊销的成本。四种子仅提供小试信号，不支持统计显著或全体系普适结论。

复用`scripts/adsorption/acceleration_benchmark.py`的同种子/同方法/同资源/同最低点检查和回本计算；CPU核时与GPU小时分开报告，不未经声明价格权重混为同一种资源。预期未来任务数、摊销口径和可接受回本周期须在执行性能试验前确定。标注/训练成本即使暂未回本也如实保留，不能只报VASP离子步下降。

只有上述证据支持且用户另行明确授权，才提出上千个构型的第二阶段；本方案不包含该扩容，也不自动继续训练。
