## 阶段目标与实际采样

本轮按用户“可以的继续”推进补数据。旧模型能否准确优化到最低点、预测误差大小、是否优化收敛，都不是继续采样或保留候选的门槛。高受力、未收敛和不同连接状态的构型均可保留为待标注环境；只有既有几何/数值保护条件用于自动采样保护。DFT 单点后续要求电子收敛、可靠原始能量/力和磁矩，不要求构型离子优化收敛。

只复用冻结随机池中的本地 Fe45 构型，不引入外部吸附位证据。保持原晶胞、原子序和底部 18 个固定 Fe；同一 control checkpoint `cfcac123cd56b866a1ea36cc780a3aee634f3aeec979bda4ae8bee2cc831e523`，每家族最多 20 步 LBFGS、maxstep 0.05 Å、ML 终止力 0.10 eV/Å，沿用原元素对距离、Fe–Fe、高度和真空保护线，不放宽阈值。

原 6 条轨迹没有重跑。新 93 条家族保留原分区：train73、development10、final_test10。MZ73 的物理 GPU1 实际模型张量位于 `cuda:0`；2026-10-22 23:27:19–23:29:27（Asia/Shanghai）生产进程实际运行，退出码 0，约 127.36 秒。该时间不包含部署/取回成本，也不是 DFT 优化加速比。87 条达到 20 步上限，6 条触及几何保护线停止；新批保存 1,881 帧，所有失败边界及 restart 保留。
