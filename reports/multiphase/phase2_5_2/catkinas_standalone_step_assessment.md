# CATKINAS 单步适用性评估

**结论。** 研究者提供的 20261106 分发包可在 MATLAB R2025b 中求解包含该吸附步骤的闭合模型。原始输入单独运行时可读入，在构建稳态方程时失败。迄今没有核实该版本能通过独立接口为孤立基元步骤返回 kf/kr。

## 官方契约与本机实测

官方手册从吸附、解离、结合、脱附等基元步骤建立稳态模型，并给出采用两种位点的完整反应示例。位点标记 `#i`、按位点区分的吸附种和整数计量数均有示例。单条件运行的日志包含覆盖度、可逆度、速率及稳态方程。随附合成氨五步单点在上轮以同一二进制成功返回五组 kf/kr。多种位点及分属两种位点的两个 H 已有本轮实证。由单个多齿分子跨库存占位的通用语法仍缺证据。[官方手册](https://www.catkinas.com/category/manual/chinese/) · [厂商对照凭据](../phase2_5_1/catkinas_environment_control.json)

安装包 ReadMe 定义了定温 Ea、G0 和修正开关。本次使用 `BarrierMode=-2`、`ThermoMode=0`、`ConsMode=0`，分别关闭额外能垒修正、热化学校正和能垒限制。输出的 `Ean/G0n` 核实了求解器实际使用的四组成对能量。HNO 热数据库缺项触发了附属热力学列表警告，本次定温速率使用输入指定的基准。程序另对位点符号的质量和绘图工具箱发出提示。报告保存了警告及原始日志哈希。[本次运行记录](catkinas_closed_cycle_validation.json)

官方 I/O 说明列出文本运行日志和矩阵结果。安装包将单点数值写入 `data1.mat`。其中 `kf/kr` 为正逆系数，`R[样本,步骤,方向]` 给出正、逆、净通量，`Rnet` 可交叉核对。覆盖度 `y` 和固定分压 `params` 的符号顺序取自日志；各气体净生成率 `Rnets` 依气体输出表的列顺序读取。[官方 I/O 说明](https://www.catkinas.com/input-output-files/) · [原生日志摘录](native_log_extract.txt)

## 四个解释的证据

| 问题 | 判定及依据 |
| --- | --- |
| A. 能否单独求单步系数 | 未确认。在核对的手册、ReadMe 和示例中，没有找到对该输入有据可复现的单步系数接口。SBQ123 仍可提供定温参数表及静态回算。 |
| B. 稳态路径是否需要总反应 | 对本次输入有直接对照。单独运行报告找不到总反应和步骤离线。闭合后引擎主动识别总反应并收敛。该对照不足以规定厂商所有模式的必要条件。 |
| C. 原始方程是否有格式或计量错误 | 逐元素与逐库存核对通过。闭合输入保留原始第一行的系数、顺序、Ea 和 G0，原生生成的一阶氢分压和两个空位因子正确。没有发现该行的格式或配平错误。 |
| D. 是否为程序缺陷 | 可复现 `sym/privsubsasgn` 左右维度不匹配。缺少厂商对孤立稳态模型的支持声明和内部诊断，根因未定。 |

单独吸附时任一 H 库存的时间导数等于该步的净通量，因此稳态只能有零净吸附。闭合后，H 从第 2 位点转移到第 1 位点，在第 1 位点被消耗，产物脱附后两类位点均可再用。本次验证只给完整合成网络增加这三步，项目实际网络的缺项仍由原门控处理。

## 厂商询问草稿

> 在 MATLAB R2025b、分发标签 20261106、编译时间 2026-11-07 的 CATKINAS 上，单独的 `H2 + #1 + #2 <-> H#1 + H#2` 能读入，但在“找不到总反应、步骤离线”后，构建速率方程时出现 `sym/privsubsasgn` 维度错误。完全相同的步骤放入配平的闭合循环可求解并返回 kf/kr。此版本是否提供有文档的独立基元系数或吸附平衡模式？如有，能否提供最小输入与输出字段；如无，能否确认上述诊断对应的适用范围？
