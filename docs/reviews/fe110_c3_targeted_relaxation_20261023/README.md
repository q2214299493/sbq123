## 计算后怎样使用

1. 分开审核调度状态、正常结束、逐帧电子收敛、原始能量/力、总磁矩和逐原子磁矩，检查结构与力坐标对应；不把“跑完80步”称为优化收敛。
2. 按原连接关系、成键变化和真实最终化学组成分类；解离结构保留正确标签，不能标成完整C₃。
3. 若存在完整、电子/磁性质控通过且可动原子fmax≤0.05 eV/Å的帧，可作为近稳定训练锚点候选。接受吸附终态仍需生产收敛标准−0.02及拥有模块的几何、兼容性审核。若未找到近稳定区，不自动扩算或强迫分子完整。
4. 较高力、下降中或解离帧经逐帧质控后也可补充训练；不以离子收敛过滤所有训练标签。每条新轨迹在训练前整体划分用途，再与已有训练帧做局域环境/近重复筛选；不把相邻帧随机拆入训练和测试，不挪用冻结验证集。
5. 将合格近稳定帧与已有偏离平衡构型共同用于后续小规模微调。模型是否加速仍要用独立C₂/C₃起点、相同DFT验收标准和总成本核算验证。本次输入准备不证明任何加速效果。
