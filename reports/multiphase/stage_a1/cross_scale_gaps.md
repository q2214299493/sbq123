## Reactor 能力逐项判断

| 项目 | 判定 | 依据与差距 |
|---|---|---|
| CSTR | 缺失 | 有模块目标和 reactor 运行角色；未找到维护中的 CSTR 物料衡算求解器及验收。 |
| PFR | 缺失 | 未找到沿反应器体积或催化剂质量积分并验证入口条件的通用实现。 |
| 理想气体 | 部分 | 已能指定气体标准压力、分压和气相活度。反应器侧 pᵢ = yᵢP、Cᵢ = pᵢ/(RT)、总流量更新与适用假设仍需绑定。 |
| 压力依赖动力学 | 部分 | 参数及 CATKINAS 导出支持气体级数与分压换算。反应器局部压力/组成变化时的受限重估尚缺。 |
| 质量衡算 | 部分 | 本征系统有元素、电荷、位点和稳态残差检查；入口、出口、停留时间和反应器整体元素衡算仍缺。 |
| 能量衡算 | 缺失 | 未见通用反应焓、热容、换热、温度耦合或可核验的绝热结果。等温条件只能由给定模型声明。 |
| 速率归一化 | 部分 | physical_factors 从 mol reference/m²、m²/kg、kg catalyst/m³ reactor 递推并交叉核对；缺物理数据时无法可靠换算。 |
| MKM/KMC → Reactor | 部分 | 运行契约已有 model_definition、rate_provider、operating_conditions 三类输入引用。尚无实现同时消费两类已验证源项并交付反应器结果。 |

## P6 和 P11 的目标接口

建议的输入包含项目、不可变网络/参数集、相/位点域、温度 K、分压及单位、标准压力、适用范围和运行证据哈希。返回每反应方向速率、正向定义、化学计量、单位与分母或直接返回物种有符号源项，明确二者间的换算。保存统计窗、种子、区间估计、能量参考相关性以及缺失项。对读取、比较、求解分别判定可用性。

对于平均场，由正逆之差计算每参考位点或位点集合的净事件率，再用已知的每体积参考量转换。晶格速率由记录窗内净事件数除以实际经过的物理时间，转换为 mol 后除以所代表体积，或先使用有证据的面积、质量换算。引擎已枚举的嵌入数只能计一次。没有金属/氧化物/界面共同基准时分别保留原始速率。

等温稳态 CSTR 应核对 Fᵢ,in − Fᵢ,out + V Rᵢ = 0。PFR 应核对 dFᵢ/dV = Rᵢ 及入口。Rᵢ = Σⱼ νᵢⱼ rⱼ，单位 mol/(m³ reactor·s)。采用质量基准积分应改用 dFᵢ/dW 与 mol/(kg catalyst·s)。对于单程可逆反应，净源项可能为负。以上为拟议验收方程，本轮未运行求解器。
