# Archived VASP2Kinetics · reuse decisions

All source and test paths below are relative to `modules/state_handoff/archive/2026-08-07/repository-items-d365620c27afc7c752614a67/VASP2Kinetics/`. Archived test names identify coverage by inspection. One bounded test was executed: `tests/test_runner.py::RunnerTests::test_timeout` passed with a sleeping Python process. Its declared external dependencies are PyYAML 6.0.3 and jsonschema 4.25.0.

| Component | Original implementation | Existing archived tests | Inputs, dependencies and scientific limitation | Active owner and decision |
|---|---|---|---|---|
| VASP parser | `src/vasp/{parser,outcar_parser,oszicar_parser}.py` aggregate energies and convergence flags | `tests/test_vasp_parser.py` | OUTCAR/OSZICAR and filesystem. A last parsed energy lacks the matched branch and geometry review. | Adsorption and registry validation. Retain malformed-file examples as potential regression inputs. Reject a parallel production parser. |
| NEB parser | `src/vasp/neb_parser.py` discovers image directories and maxima | `tests/test_vasp_parser.py::NebParserTests` | Image OUTCAR energies can be incomplete. A maximum does not establish a saddle or acceptable forces. | `scripts/neb_agent/` and `scripts/ts_strategy_engine/`. Reject as execution or TS authority. |
| ReactionRecord | `src/kinetics/{schema,builder}.py` combine YAML step definitions with parsed states, energies and quality flags | `tests/test_kinetic_dataset.py` | Dataclasses, PyYAML and VASP records. String species lists and optional energies do not fully identify geometry, charge or occupied site types. | Reaction network / kinetic data. Adapt explicit missing values and source linkage. |
| KineticDataset | `src/kinetics/{schema,registry}.py` serialize and register JSON records | `tests/test_kinetic_dataset.py::RegistryTests` | Local read/write collection. It cannot enforce production registry foreign keys, immutable transactions or review history. | Calculation Registry. Keep grouping as an interchange concept only. Reject the second registry. |
| Parameter handoff | `schemas/kinetic_parameter_handoff.schema.json`, `src/kinetics/{handoff,handoff_support}.py` | `tests/test_kinetic_handoff.py` | jsonschema, source/file hashes, canonical dataset binding, energy identities and manual review references. Transfer still needs current compatible local IS/TS/FS, occupation convention, kind of energy, thermal evidence and rate units. | Kinetic data and registry compatibility. Adapt evidence binding; defer any import/promotion. |
| Scientific validator | `src/kinetics/{validator,validation_structure}.py` checks fields, elemental formulae, convergence flags and barrier differences | `tests/test_validator.py` | Parsed record and declared formulae. Cannot establish geometry, vibrational acceptance, per-type site balance or method compatibility. | `scripts/scientific_validation.py` and owning scientific gates. Adapt arithmetic cases as contract tests. |
| CATKINAS generator | `src/catkinas/{generator,species_writer,reaction_writer,parameter_writer,mapping}.py` emits species.dat, reactions.dat, parameters.dat and mappings | `tests/test_catkinas_generator.py` | KineticDataset and validation statuses. Installed MATLAB entry reads a named mechanism/conditions input. These files provide an intermediate table. | Baseline MKM. Retain mapping concept. Reject files as native MATLAB input. |
| Zacros generator | `src/zacros/{generator,lattice_writer,mechanism_writer,energetics_writer,species_writer,mapping}.py` emits labelled lattice and reaction text | `tests/test_zacros_generator.py`, `tests/test_zacros_cli.py` | Surface YAML, records and energies. Labels and a barrier do not specify a lattice graph, event patterns, neighbouring relations and cluster expansion. | Surface KMC. Adapt checks for explicit site information. Reject spatial readiness. |
| Simulation runner | `src/runner/{base_runner,catkinas_runner,zacros_runner,execution_log}.py` records argv, streams, statuses and timeouts | `tests/test_runner.py` | Standard-library subprocess with shell disabled and wall timeout. Child-process cleanup, allocated resources and external authorization need separate verification. | Existing execution gates/backend routing. Retain timeout failure cases for a future adapter. |
| Result parsers | `src/analysis/{catkinas_parser,zacros_parser,parser_utils,result_schema}.py` normalize exports, process statistics and partial states | `tests/test_result_parser.py` | Explicit text exports/mapping; CATKINAS expects coverage.dat etc. Zacros can read procstat blocks but counts alone lack a site/time normalization for TOF. | Baseline MKM / surface KMC. Adapt missing-data semantics. Require native MAT and count/normalization fixtures. |
| Analysis/reporting | `src/analysis/{analyzer,ranking,report,result_writer}.py` rank reaction rates/coverages and render summaries | `tests/test_analysis.py` | Normalized result schema and source mapping. Ranking a rate does not establish DRC, convergence or uncertainty. | Owning kinetics and sensitivity modules. Adapt reporting after units and numerical checks exist. |
| Workflow state | `src/workflow/{state,pipeline,executor}.py` persist stages and coordinate per-case execution | `tests/test_workflow.py` | Local state JSON, CLI commands and registries. Independent transitions would duplicate repository state and decisions. | `scripts/state_manager/` and owning gates. Reject pipeline and state store. |

No archived component was copied into active source. The native input/output evidence used for these decisions is in [the engine assessment](external_engine_compatibility.md).
