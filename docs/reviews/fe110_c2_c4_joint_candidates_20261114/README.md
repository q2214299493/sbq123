## 3. 坐标、位点与隔离方法

所有候选均绑定原有 `.vasp` 文件和逐帧JSON的原始字节SHA，保持Fe45、原子序、晶胞和底18个Fe固定约束。位点报告同时给出：

- C/H/O的1起始原子索引、最近Fe索引与三维距离；
- 按既有共价半径规则计算的Fe接触邻居、C–C距离和吸附质接触图；
- 相对已验证清洁表面的名义top/short bridge/long bridge/hollow及横向偏离；
- 总C数、最大C–C连通分量、吸附质分量数。

这些是几何诊断，不能证明电子键级、稳定吸附位点或全局极小值。随机几何与短ML轨迹中的接触变化，不能被标成已验证DFT反应路径。对于含分离H/O或C碎片的构型，不将总分子式误称为完整吸附分子。

隔离参考包括：原有513个保留几何、3个已有Fe45的C₃独立验收种子、26个拟保留的外部C₂低力轨迹帧，共542个来源绑定；另比较536训练坐标、861个已有标签几何和11个其他CHCO训练/标注请求坐标。78/53/16分区仍保留，另6个C+H路径验证标签继续禁止进训练。

使用清洁Fe(110)实际36个保留吸附面的空间群操作、XY周期最小像和同元素吸附质排列。相同约束角色的Fe先在比较表示中与清洁晶格对应，再评估吸附质RMSD与可动Fe RMSD的较大值；原始原子序、坐标及力均不改动。单位测试发现并修正了等价Fe索引置换处理，最终隔离结果已重算。

保留来源按更保守的吸附质对称RMSD≤0.20 Å阻断；候选间按包含可动Fe的对称距离<0.10 Å去冗余，每个家族最多一个首批名额。同坐标标签只可在完整坐标/精度/原子映射审核后复用；几何相近不授权借用邻居力矢量。

20个最终备选与保留来源的最小吸附质对称RMSD约1.007 Å，同组成候选间最小完整比较距离约1.092 Å。已知存在先前SCF或磁性失败的0021/0028/0086家族没有占用本批20个名额；这不意味着这些家族其他坐标都无效。
