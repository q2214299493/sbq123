# B.1.1 · Existing V2 kinetic rate contract audit

Audit basis: publication commit `49ca89afae5d44f06acda41987d2422a822167db` and the [accepted engine architecture](../../../docs/decisions/adaptive_mkm_kmc_optional_reactor.md). The baseline already had two schemas, one V2 reader, one stoichiometric projection and 56 V2 test cases. There is no engine-independent rate-output producer or job creator in this entry path.

## Field assessment

| Field or quantity | Finding and interpretation |
| --- | --- |
| `format`, `schema_version` | Exact constants `kinetic-rate-output/2` and `2.0.0`. Both are mandatory. Object properties are closed. Stoichiometric map keys are species or inventory IDs with validated counts. |
| `project_id`, `dataset_version`, `network_version` | The project ID scopes the records. These version digests identify the upstream parameter dataset and reaction network by canonical content. Neither identifies a particular output. The parameter generator hashes its payload excluding its own digest. The two archived digests reproduce. |
| `output_binding.dataset_id`, `.run_id`, `.native_inputs` | Optional complete binding added here. The ID identifies a rate dataset within its project, the run ID identifies its execution, and each named input has a file SHA-256. An earlier record lacking the block has unknown output identity and input/run binding. The reader checks within-document consistency. Cross-file ID uniqueness is outside this offline reader. |
| `reaction_rates[].reaction_id`, `.parameter_set_id` | Unique reaction and parameter bindings in the selected content-addressed parameter dataset. The archive contains each row's Phase 1 parameter set. There is one raw hash for the containing dataset. There is no separately authenticated artifact per parameter row. |
| `engine.name`, `.version` | Required. The native input set, native output artifact and run ID together identify the reported run when supplied. A locator or an engine version in isolation does not establish that a run occurred. |
| `conditions.temperature_K`, `.pressure_Pa`, `.partial_pressures` | Required operating point in K and Pa. Partial pressures can be a bounded declared subset, an empty known list or null. No gas composition is inferred from the total. |
| Gas standard state and surface activity | Referenced parameter records carry `standard_states.gas_pressure_Pa` and `surface_activity_convention`. The benchmark manifest explicitly gives 100000 Pa and fractional site occupation. The V2 conditions block does not itself attest that all rows use identical activity conventions. A comparison requires the referenced definitions. |
| `validity_range` | A declared range uses inclusive bounds in K and Pa. Null means the range is unavailable. A single operating point supplies no inferred extrapolation range. |
| `native_normalization` | One common native extent, time and denominator per document. Preserve `denominator_value`, literal `denominator_unit`, `reference_id` and `definition`. Optional `basis_kind` and `inventory_ids` distinguish site, site pair, lattice site, cell, area, mass, volume, other or unresolved. Raw labels alone remain unresolved for conversions. Inventory IDs can include interface inventories. |
| Forward and reverse **coefficients** | Owned by the bound parameter laws. Gas activities form as partial pressure divided by standard pressure, or a pressure order is carried in the exported coefficient unit. At unit dimensionless activities the coefficient is per second. Native pressure laws with order n carry pressure⁻ⁿ s⁻¹. The Zacros exporter additionally accounts for directed event embeddings. There is no general coefficient field in either V2 source/flux schema. |
| `forward`, `reverse`, `net` | The first two are directional event fluxes, the third is signed reaction progress. All three inherit extent per native time and denominator. Known zero, missing observation (null) and excluded direction (`not_applicable`) are distinct. A known net despite an unobserved direction requires independent `net_evidence`. Known directional bounds still apply. |
| `source_terms.species[].{species_id,net_production_rate}` | Molecular production, or mol of species for molar extent. Every species named in the parent reaction set gets one row. The full parent specifies reaction IDs, input parameter version, output binding and native basis. Spectators have zero coefficient even when progress is unknown. |
| `source_terms.site_inventories[].{site_id,net_vacancy_rate}` | Vacancies released minus consumed, summed independently for each inventory. The numerator counts vacancies or mol of vacancies. Adsorbate multiplicity belongs in the appropriate inventory contribution. A molecule spanning two inventories is still one molecule. |
| `provenance.dataset`, `.network`, `.native_output`, `net_evidence` | Each artifact carries a path and SHA-256. Canonical version digests and raw file digests have different domains. The reader validates declarations without reading caller-supplied paths. It does not authenticate labels or prove independence of an asserted net observation. Physical interpretation requires the referenced evidence. |
| `validation.status`, `.review` | A scientific review declaration needs the existing review artifact for accepted/rejected status. Schema shape and arithmetic are checked in that order. Solver convergence belongs to the native receipt, KMC uncertainty to trajectory/statistical evidence, and scientific acceptance to the owning review. No validator call generates any of those decisions. |

Species and vacancy sources use respectively Σ(products − reactants) × net progress and Σ(released − consumed) × net progress, summed over reaction rows. An unavailable net affects only identities with a nonzero coefficient in that row. The cross-inventory regression obtains one molecular source of +2 and a vacancy source of −2 in **each** inventory. Neither site counts nor molecular source rates are interchangeable with a coverage fraction.

## Entry points and ownership traced in code

| Entry or caller | What actually happens |
| --- | --- |
| `scripts.multiphase_contracts.main → read_unique_json → validate_bundle` | V1 bundle schemas plus links, stoichiometry, review and run checks. Valid historical V1 remains readable. V2 format/fields fail this reader. |
| `scripts.rate_output_v2.main → read_unique_json → validate_rate_output_v2 → generate_source_terms` | Explicit V2 command or direct call. Local schema resources, duplicate keys, version, finite numbers, pressure/range, net and both source checks. Missing/unknown versions and hybrids fail here. No version sniffing, fallback or migration. The source helper expects schema-conforming reaction rows. |
| `scripts.kinetic_parameters.engine`, `.laws`, `.export` | Create and hash the parameter dataset, enforce the gas order of dimensional prefactors, export separate CATKINAS pressure-based and Zacros per-occurrence coefficients. Species/reaction identity, rate laws, standard states and parameter evidence continue to use their existing records. |
| `scripts.baseline_mkm.results.read_single_point`, `single_point_result.reconstruct` | Read MAT arrays and log symbol maps. Check coefficients against parameter exports, multiply by gas/surface/vacancy activities to reconstruct fluxes, check native net and balances. The established single-point report has its own format. |
| `scripts.surface_kmc.native.render`, `scripts.native_model` | Assemble and check native lattice/event inputs. The maintained scope has archive-member tests for Zacros outputs. The historical VASP2Kinetics package has a separate `src.analysis.zacros_parser.parse_zacros_result` with its own parser regression. Neither writes V2. |
| New tasks, SPC, comparison and Reactor | A caller selects the V2 reader explicitly for this contract. No task-creation path in these modules dispatches to the V2 reader automatically. Engine selection, native extraction, cross-validation and macroscopic reactor consumption retain separate owners. |

## Decisions on changes

| Classification | Existing behavior and issue | Decision, compatibility and verification |
| --- | --- | --- |
| MUST_FIX_NOW · unavailable progress | Numeric-only flux/net fields forced omission of the record or a fabricated zero. The projection could not propagate a missing net. | Extend the two existing schemas and existing arithmetic. Known values retain their representation. Excluded and unknown directions differ. Independently measured net requires a path/hash and feasible sign/bounds. Tests cover missing directions, explicit zero, spectators, unaffected inventories, contradictory evidence and multi-inventory molecules. |
| MUST_FIX_NOW · physical denominator | Value, free-text label, reference and definition were preserved, but automated readers could conflate different physical site populations. | Add an optional typed kind and require distinct inventory IDs for the three declared site kinds. An earlier unlabeled kind implies no available conversion. Tests cover all kinds, wrong/absent identities, same-type pairs and preserving unscaled rates. |
| MUST_FIX_NOW · output and input identity | A parameter dataset version can be reused by many runs. Even with an output artifact, V2 had nowhere to declare a rate dataset ID, run ID or native model input hashes. | Add one optional closed binding. If present all fields are required, including a nonempty array of distinct input paths. Older V2 output remains readable with unbound identity. Tests use two runs of the same parameter version and reject partial, conflicting or unknown fields. |
| ALREADY_SATISFIED | Version isolation, closed shapes, V1 imports/CLI, separate species and site maps, source reaction set and basis inherited from the parent, distinct physical units for coefficients and fluxes at their owners. | Keep the readers independent and the sources nested. Exercise legacy fixtures, crossed readers, both adapters, MAT archive fields and Zacros archive/parser tests. |
| MUST_FIX_BEFORE_B1_COMPLETE | For independently consumable native exports, readers still need explicit verified bindings from the real run to the declared parameter/reaction IDs, standard states, rate-law units, solver/statistical receipts and the physical scope of each output. | Qualify these at the consuming checkpoint. For a standalone or detached source artifact require a parent identity, exact reaction set and basis. No standalone artifact is produced here. |
| DEFERRED | No V2 native result exporter, cross-engine statistical comparator, task-creation integration, physical normalization converter or reactor orchestrator in this path. | These are later deliverables. There is no new schema family, migration, engine selection or native execution in this audit. |

The format and exact schema version remain as published. Existing numeric V2 records validate with this reader. Readers pinned to the original closed 2.0.0 schema can reject records using the additive fields or unavailable values. For interchange with those readers, identify the schema revision and retain the original document. No downgrade or silent field removal is performed.
