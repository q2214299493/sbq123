# Phase 3.0 单点 MKM 工作流验收

四步合成 Ni/Cu 界面在新工作流中通过了真实 CATKINAS 单点验收。真实 Fe(110) CH* + CO* → CHCO* 在生成原生输入前收到逐反应缺项报告。基线为 `a537ab054ecc7e1b5030a031fb9d3cc666f1a89a`。

## 可以执行的工作

从仓库根目录运行 `python -m scripts.baseline_mkm.single_point --help`。模块 README 给出了 prepare、execute、status、Registry 批次生成和审核入口。prepare 校验版本摘要，在网络评审绑定上重新生成动力学数据，读取 H7 工单及 question_id，随后装配模型。execute 消费研究者提供的单次授权，复核目录、状态摘要、工具和输入，在隔离目录运行固定的 MATLAB 调用。每阶段使用独占回执，重复执行同一 run 会被拒绝，已结束的进程、未确认的收敛与独立验证分开记录。可通过 status 查看运行中的阶段或失败位置。已有模型装配、结果读取、Registry 审批和 NEB 专用科学决策入口继续可用。

| 文件 | 职责 |
| --- | --- |
| scripts/baseline_mkm/single_point.py | 资格、票据、只写一次的运行清单和回执、执行、状态及 H7 交接数据 |

| tests/test_mkm_single_point.py、tests/test_catkinas_closed_cycle.py | 模拟进程异常与多相端到端试验、真实集成显式入口、既有模型构造器的网络输出 |
| modules/baseline_mkm/README.md、本报告目录 | 调用方式、审批格式、网络及配置、归一化结果、原生证据与缺项报告 |

复用了 Reaction Network 版本、Phase 2.4 generate 和 exporter、CATKINAS assemble/publish、MAT/log 解析器、Registry plan/apply，以及 H7 工单身份和人工交接格式。项目位点定义来自版本化网络。合成氧化物和合成 Fe 表面分别使用酸位/碱性氧和台阶/口袋位点，走同一入口，原生执行在这些 CI 用例中由固定数值样例模拟。

## 真实原生验收和独立数值检查

在 400 K 和 1.6 bar，总反应 H₂ + 2 NO ⇌ 2 HNO。H₂、NO、HNO 分压分别为 1、0.5、0.1 bar。授权 CATKINAS 分发标签 20261106，程序自报 20230524，MATLAB 25.2.0.2998904 (R2025b)。成功运行耗时 192.29 秒，外部限时 210 秒。Phase 2.5.2 事件所列的九个原始目录文件逐字节复核通过。新运行的输入回显与原输入同为 SHA-256 `b793e6f37f2262e4a006f912d18950c17581ccc014aa9779008741a4e31890f8`。

| 独立检查 | 实际结果 |
| --- | --- |

| 双位点 | 两个库存各为 1，空位分数 0.29168655、0.30332052，库存残差均为 0 |
| 四步质量作用通量 | 用 MAT 系数、覆盖度、分压和空位分数逐向重建，原生净通量一致 |

每个基元步骤检查元素、电荷和位点守恒。检查同时覆盖输出的气相元素流、给定温度和分压、反应序号、原生能量、覆盖度范围，以及原生输入回显。全量日志和运行源文件保存在开发目录的 `archive/phase3_0_native/validated/run`。发布的 MAT 和日志摘录可独立重现随附结果。CATKINAS 报告绘图后端降级、将 #1/#2 识别作未定义原子符号，以及 HNO 热力学表缺项时使用默认值；本例使用 ThermoMode=0 和显式定温步能，已逐步核对实际施加的能量与系数。[运行清单](benchmark_manifest.json) · [标准结果](result.json) · [原生 MAT](data1.mat) · [日志摘录](native_log_extract.txt)

第一次真实执行得到收敛输出，但初版方程校验把日志后部的速率汇总表也当作输入方程，导致流程拒绝。修正后先复核原始文件，再用新的运行目录执行上述完整验收。两次记录独立保留。

## 工单、注册与真实案例

本机生产 H7 工单库只读检查得到零条工单。本次给合成基准使用明确标注的工单夹具。使用 H7 原版 TicketStore 的隔离副本验证了交接数据可保存并出现在 Supervisor 快照中。生产看板没有新增交接。Registry 在独立数据库通过既有计划、哈希绑定审批和申请流程写入 15 行，包含 1 条计算、12 条文件、2 条候选结果。两条标量为合成 TOF 和稳态余额。生产 SQLite 写入为零。[工单验证](ticket_handoff_validation.json)

真实 Fe(110) 在 QUALIFICATION 阶段列出 11 项缺口，包括 IS/FS Gibbs 修正、催化相、位点与空位计量、电荷、可逆性和有来源的已评审动力学参数。保留电子能和局部 TS 证据，完整 Gibbs 能垒、逆速率和未知条件继续为空。该案例没有原生输入、MATLAB 进程或 MKM 结果。[Fe(110) 缺项报告](fe110_qualification.json)

常规测试覆盖资格、混用版本和条件、不同相与位点、模糊符号、反应序号、缺 MAT、日志损坏、进程失败及超时、改动过的输入或授权、独立通量与守恒、只写一次和可追溯注册。首次 Registry 计划因候选标量缺来源声明而拒绝；补充与结果哈希绑定的候选记录后，三个材料案例均通过。额外失败来自开发目录已有的 NEB SSH 上传函数向旧模拟器传入 stdin；单独装载此次修改前的执行门，同一测试仍在上传处复现 TypeError。开发目录的上传代码和旧测试保持原状。

现有原生验证适用于固定温度、分压、分数活度和每类库存归一为一的可逆模型。单向反应、不同物理位点密度和多齿物种的 CATKINAS 编码尚待专门验证。没有真实催化剂 TOF、选择性、DRC 或参数扫描结论。下一项可执行工作是由研究者审阅 Fe(110) 位点提案，确认三个吸附物的位点集合与数目及反应两侧空位计量，然后重跑该网络的位点配平检查。
