# 冻结 536 与 536+9 纯力微调增量预检

9 个 C₂/C₃ 单点已整理成独立增量清单。新增 1 个 C₂H₃、3 个 C₂H₂O 和 5 个 C₃H₂O，均为高力固定坐标标签。512/536 原包、78 个开发、53 个保留测试及 16 个观察隔离成员保持冻结。

## 增量来源

每行绑定 REICO 帧与逐帧元数据、原作业回执、输入 POSCAR、OUTCAR、归一化力表行哈希、原始力表的零基字节偏移/长度/字节哈希，以及隔离记录文件和对应行的 SHA256。POTCAR 留在服务器，只读校验哈希。归档复制了 9 份 OUTCAR 及核查所需的小型输出和文本输入。

9 点均在训练侧已有来源家族中，与保护家族和作业无交集。重算了对冻结训练、三隔离分区、历史保留库及补充保护来源的表面对称距离，最近训练及保护距离分别为 0.127 Å 和 1.080 Å。13 个批内同组成对照的最小距离为 1.407 Å。新增帧的最大可动力为 1.535–8.329 eV/Å。九条标签保留逐原子原始力、同坐标与收敛证据和正 Fe 局域磁矩等级。

两条微调臂从同一冻结 536 checkpoint 载入权重，新建优化器、调度器和 AMP 状态。冻结 checkpoint 的 SHA256 为 `2aaed376a1d5ad66999710f7d252aff79c45569f2a6a95510d4bff9bbc70acc0`。原生 78 帧开发力指标为 0.0619943341 eV/Å。

每臂拟用 1 GPU、4 CPU、32 GB，最多 0.5 GPU 小时，两臂合计最多 1 GPU 小时，自动重试次数为 0。历史 536 训练分配耗时 177 秒，按迭代数缩放给出 177/180 秒的量级估计。现有采样器以数据集长度为一个 epoch，两臂总迭代相差 18 次（约 1.68%）。实际 optimizer 更新须单独记录。

新增帧的总采样概率为 9/545（1.651%）。两 epoch 期望抽到 18 次并覆盖约 7.78 个不同新增帧。在本机 CPU 用现有采样器按清单顺序回放，seed 42 实际抽到 9 次、覆盖 4 帧。额外回放中，仅对新增帧取 2× 时抽到 25 次、覆盖 8 帧，4× 时抽到 50 次、覆盖 9 帧。两种增权均仅作敏感性诊断。主对照维持原均匀分布，未来训练应记录逐帧实际访问量。
