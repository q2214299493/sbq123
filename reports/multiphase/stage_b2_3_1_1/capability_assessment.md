# 一个 CO₂ 同时占据两套库存的原生能力审查

**证据结论**　当前 SBQ123 CATKINAS 适配器对此足迹返回 `unsupported`。厂商手册 §4.3 明确给出跨多个位点的物种标记与覆盖度命名。从 §4.1 和 §4.3 可以写出候选方程 `CO2 + #1 + #2 <-> CO2#1#2`，桥式分子的覆盖度变量为 `Q1x2_CO2`。未找到该变量在 4:3 不等库存中如何归一化的规定，亦缺本例原生结果。20261106 分发包对本算例的求解能力为 `unverified`。[厂商手册 §4.1、§4.3](https://www.catkinas.com/category/manual/) · [方程样稿](oxide_CO2.m.in)没有本例的解析器错误或收敛记录。[独立复核回执与原文件摘要](evidence.json)

本次拟检验的最小逻辑循环只有两个方向。正向从气相拿走一个 CO₂，分别消耗一个酸位空位和一个氧位空位，产生一个桥式分子；逆向一次同时归还该分子和两个空位。这是可逆吸脱附交换，可以在平衡时保持非零的双向交换速率，净周转为零。它没有连续产物出口。该循环是本轮指定的测试假设；原结构记录中的可逆性仍为未知。

给两个位点各写一个 CO₂ 会使分子数、碳和氧的计量翻倍。只给一个位点加物种后缀会丢掉另一条占位约束。把两个位点合为一个“位点对”也无法回读 4:3 的独立库存。方程样稿保留一个产品 token，并列明已知的两个初始空位分数。温度、冻结分压、能量和桥式覆盖度采用显式待填项；样稿的文件哈希只标识审阅对象。[数值参考](numerical_reference.md) · [执行准备状态](execution_readiness.json)
