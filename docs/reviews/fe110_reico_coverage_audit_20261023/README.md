## 输入、分区和方法

- 两批轨迹共1995帧，其中1988帧通过原几何护栏。本次SOAP覆盖计算只用训练分区1597帧、79家族；参考点为原选中的233帧。
- 原开发/最终测试分区不变。513份保留集几何只参与数据隔离检查，没有使用其力、能量或模型误差做选点或调参。旧16份已观察留出几何从原始目录按完全相同SHA256定位，不因未复制到新包而跳过隔离。
- SOAP使用DScribe 2.1.2；Fe/C/H/O，r_cut=5 Å、n_max=4、l_max=3、sigma=0.5 Å，XY周期、Z非周期。544维向量逐原子归一化。
- 中心为全部吸附原子，以及距吸附原子3 Å内的可动Fe。按C/O/H/Fe分别比较，未对整块铁层做平均。
- 距离为1减归一化向量内积。各元素阈值来自233帧中排除同一轨迹家族后的最近邻距离p95；同时保存p90/p99。它是本轮内部诊断设置，不是论文原阈值、精度保证或化学完备性标准。
- 原始坐标去重仍作为几何保护。新增建议与既有选点按0.10 Å检查，与保留集按0.20 Å保守隔离；最多每个训练家族建议一帧。

4. C3应先核验现有近稳定来源。远端旧路径`~/sbq/Fe110/adsorption/care_c3h2o_rebuild_pair_20260717`在`sunboquan-codex`当前账户下，Python目录检查返回`PermissionError: [Errno 13] Permission denied`。未切换未经授权账户或修改权限；无法复核这些旧任务的收敛、原始力、磁矩和最终连接关系。
