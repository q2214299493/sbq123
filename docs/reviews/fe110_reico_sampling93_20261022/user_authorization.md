# 继续随机采样和构型去重的授权

用户纠正了阶段目标：现有模型不准正是补充数据和微调的原因，不能要求旧模型先准确优化到最低点。助手据此明确后续流程为随机起点/短程轨迹采样、保留未收敛和失败附近构型、按几何差异去重、DFT 单点标注后训练，再评估新模型。用户回复：

> 可以的继续

本轮将该授权具体执行为：复用已完成六条轨迹，对冻结随机池中其余 93 个起点各运行最多 20 步 ML 采样。沿用同一 control checkpoint、GPU1、每步位移 0.05 Å、ML 终止力 0.10 eV/Å 以及原有元素对/Fe–Fe/高度/真空保护线。终止力只控制轨迹运行，不是选点或继续采样的准确性门槛。单次最多 600 秒，返回数据上限 96 MB，无自动重试，不影响其他任务。

冻结 99 个成功生成家族原有的 train/development/final_test 分区；六个已有家族不重跑，失败家族 0084 不补造。每个家族最多选 3 个构型，全部候选最多 297 个，计入已有 12 个 DFT 标注。选点只使用几何差异、轨迹阶段和来源/分区约束，不用旧模型能量、预测准确性或是否优化收敛决定保留。相同轨迹不得跨数据分区，近重复跨分区构型必须隔离。

本批执行范围是短程 GPU 采样、原始帧及失败记录取回、work 侧审核和去重候选准备。DFT 标注输入可以准备；不在本批自动提交新 DFT、启动训练、变更生产模型、放宽几何保护线或宣称 C₂/C₃ 加速。具体 DFT 批次和训练资源在可审阅输入形成后按各自执行门处理。
