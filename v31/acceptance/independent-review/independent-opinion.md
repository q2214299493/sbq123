# 独立复核意见

**V3.1 约定范围的软件功能验收通过。** 结论适用于最终冻结源码及 SHA-256 为 `17869452de114fd28c6dac0becc9204d07eafe70c744bbfd5d9a9d164674d6bd` 的补丁。第一版冻结源码仍接受仅有速率常数的记录，第二版对相同反例返回 `insufficient_evidence`，差值为 `null`。

**回归。** 从原审计 JUnit 和交付中的逐测试 JUnit 记录独立解析、核对 ID 和最终状态。MKM 为 501 通过、1 跳过，KMC 为 523 通过，上一轮独立控制 16 通过。原审计的全部 1,024 个 ID 保留原状态。本次独立复核直接执行边界探针，回归套件由实施方执行。原生授权用例保留跳过。

**执行边界。** 正例跨模型数值来自预先加载的分析点和窗口，只有读取层被替换。文件入口及合法 H₂ 映射通过冻结的两个软件入口重放原始文件。KMC 使用该合成夹具记录的惰性程序摘要。异构化反例直接检验轨迹投影。未启动原生求解器。此结论仅涉及约定的离线软件功能，原生联合科学资格、统计收敛和真实 Fe 体系均未评定。
