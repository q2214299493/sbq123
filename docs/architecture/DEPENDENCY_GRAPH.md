# Source and runtime dependencies

[IMPORT_EDGES.csv](IMPORT_EDGES.csv) lists every resolved active scripts-to-scripts Python import in each projected role, including imports inside functions and relative imports, with source line numbers. Topological sorting checks cycles. Standard-library, optional external packages and dynamic subprocess calls lie outside that graph.

The kinetic dataset generator imports neutral laws, network construction and schema validation. Engine-owned parameter tables consume neutral export validation. Legacy kinetic_parameters.export re-exports adapter functions for compatibility. The release compare entry verifies both role versions; KMC comparison starts the MKM role_entry in a separate isolated Python process. Worktree arguments resolve a materialized role, whose bytes and version are checked. The two engines never share an imported scripts module in that replay.
