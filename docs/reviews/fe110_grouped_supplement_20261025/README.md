## 归并与优先规则

- 只比较相同组成、相同距离判据连通图的构型，保留成键连接关系的差别，不跨图硬合并。连通图不区分键级，也不证明相同电子态。
- 复用原有缓存 SOAP、元素分开的固定覆盖阈值。对两个构型双向计算各局域环境到另一构型同元素环境的最近余弦距离，取最大的归一化距离；一簇内任意两帧的值均不超过 1。
- 采用确定性的贪心完全连接分组，避免 A 接近 B、B 接近 C 就把远离的 A/C 串成一类。分组数不是已证明的最少数。
- 首轮优先：吸附物为单一连通体，且至少一个原类型在 1.20、1.25、1.30 三种判据下持续缺失；在这些持续缺失类型中优先选对现有标签 SOAP 距离较大的代表。
- SOAP 超阈值、但不是单一连通体的对象留作备选；其余环境暂缓。暂缓只是当前任务的优先取舍，不等于结构无效或以后不会需要。
- 未使用模型力误差、不确定度或保留集力/能量排序；没有把未知 DFT 力补成零，也没有把几何相似当成力相同。

12 个是这轮规则得出的诊断规模，不是已证明必须或足够的 DFT 数量。特别是这 12 点的 SOAP 比值均低于现有内部阈值：选它们的额外依据是连通图内持续缺失的配位组合，而非宣称它们存在已知的大力误差。
