## 几何相近构型的DFT力差

在110份通过质控的训练标签内部，按相同组成匹配同元素原子，保留Fe编号、晶胞及XY周期分支，不作刚体旋转对齐。找到13对几何向量RMSD小于0.20 Å的构型；全部来自同一轨迹家族，距离0.10 Å以内的对数为0。没有使用开发/最终测试标签，也没有将旧248行混入这组配对比较。

“力差”定义为匹配后吸附原子力向量之差的RMSE，即sqrt(mean(|F₂−F₁|²))，不是分量RMSE，也不是模型预测误差。13对的该值为0.449–9.083 eV/Å。

| 同家族构型对 | 几何RMSD / Å | 吸附原子力差RMSE / eV·Å⁻¹ | 最大单原子力差 / eV·Å⁻¹ |
|---|---:|---:|---:|
| 0066 step000 → step007 | 0.19539 | 9.0833 | 15.5281 |
| 0082 step000 → step006 | 0.16483 | 7.4653 | 13.9380 |
| 0036 step000 → step015 | 0.14771 | 5.6856 | 10.2961 |

最大差异那一对，整体RMSD约0.195 Å，但H51–C46距离从0.860462变为1.186278 Å；H51力模从18.479153降到3.017383 eV/Å，力向量变化15.528111 eV/Å。两帧的主截断连接图和Fe配位联合类型相同。**整体RMSD和离散连接类型会掩盖局部键长的连续变化。** 这个结果与压缩C–H环境释放后的陡峭力变化相符；不能仅凭此断言标签错误或需要重算。

该对总磁矩变化约1.9409 μB，最大单Fe局域磁矩变化0.378 μB；全部Fe仍为正磁矩。当前数据不能严格分离几何响应与磁性分支贡献，也不能证明不存在其他更低磁态。

13对均经独立的同元素置换穷举复核，与Hungarian匹配得到的几何RMSD、力差完全一致（绝对容差1e−12）。这些帧保留，不做单纯按几何距离的二次删除；未改变原选点。

## 是否补标的结论

1. **暂不增加随机DFT，也不为187种遗漏联合几何类型逐个补标。** 本次仍有83份已提交作业在该快照下运行/排队；先消化已有计算和已合格标签更有依据。
2. 当前数据已支持“近邻构型可能有显著不同的真实力”，但没有获得187个未选代表帧的DFT标签，不能直接判断它们各自的重要性或模型误差。原先RMSD<0.10 Å的71个代表仍未被本轮直接验证其力。
3. 已通过的离平衡标签可以进入小试训练包准备；混合兼容旧数据时需保留来源、分区和整作业隔离，不能宣称低力C₂H₃/C₃缺口已经补齐。
4. 若后续专门改善优化末段，优先核验已有C₂H₃/C₃低力来源；缺失时再讨论小规模定向补充。用户已搁置的两项C₃优化保持搁置，本报告不是新计算授权。
