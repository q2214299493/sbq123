# 536 与 545 帧纯力微调对照

两组在 BUCT2 依次完成，同用冻结 536 权重、全新优化器、单张 A800、两轮及学习率 1e−5。两组使用同一份 78 帧开发数据库选最佳权重。Slurm 确认两组均完成、退出码均为 0:0、每组申请限时 29 分钟。

| 训练组 | 作业 | 实际参数更新 | Slurm 用时 | 78 帧平均力向量误差（eV/Å） |
|---|---:|---:|---:|---:|
| 536 帧 | 3848 | 1072 | 2 分 49 秒 | 0.060013 |
| 545 帧 | 3849 | 1090 | 2 分 51 秒 | 0.057173 |

545 组在同一开发集上的平均误差下降约 4.7%。C、O、H 和靠近吸附质的可动 Fe 的分组误差也下降。两组的训练数据量使总更新数相差 18 次。本轮结论只覆盖这个训练配方和 78 帧开发集。

545 组的原生逐步记录表明，9 个新增结构在第 1 轮和第 2 轮各参与参数更新一次。训练过程逐步记录真实送入的结构 ID 和优化器是否更新，核对了 CPU 预跑顺序与实际过程。

计算证据位于 `calculations/fe110_reico_pilot300_20261022/force536_545_comparison_20261119_v1`。其中 `comparison_summary.json` 绑定共同的初始权重和开发数据，两个子目录保留各自的原生最佳权重、Slurm 日志和真实训练记录。

三台 GPU 服务器均做了资源查询。BUCT2 经该任务的 CPU、分配内 CUDA 和实际设备 UUID 核验后用于两组训练。两次分配的物理卡不同，均为同一台 BUCT2 的 A800。冻结 512/536 包与 78/53/16 分区保持不变。本轮未提交 DFT，未用保留测试或隔离数据选模，未替换冻结模型。
