Fe42 始终是 O 最近的 Fe。O–Fe41 连续拉长，配位计数在既定阈值处从2降到1。改变截断后，较紧的2.376 Å在两端都是1个接触，较宽的2.574 Å在两端分别为3和2个。这说明几何差异真实存在，但整数配位变化依赖截断。相对已有 `step000` 的全结构对称距离仅0.0541 Å，当前没有换到另一主锚点的证据。

同家族 `step000/008/014` 已有合格力与局域磁矩。三帧的 O–Fe42 距离分别为2.187、2.419和2.599 Å，可以先利用这三个点检查沿 O–Fe 拉长的力表现。特别是 `step000` 上，已有冻结536的 O 力向量误差为0.249 eV/Å，DFT O 力模长为7.755 eV/Å，方向余弦为0.99949。这些是已标注训练帧的实测误差。第4点的真实力仍未知，三帧都不能替代它的同坐标标签。先延后该点可把预算留给连接与主配位差异更大的构型。首批因此暂不新增 C₂HO 单点。
