## 判断方法

1. 分开核对：原始构造 → 首次 DFT 输入 → 后续收集的 POSCAR → DFT 输出。收集到的 POSCAR 可能是续算起点，不能据此单独推断迁移发生在 ML 阶段。
2. 用共同的真实 Fe45 洁净表面、xy 周期边界及项目已有 Fe(110) 位点生成函数计算投影；同时保留最近三个 Fe 距离和吸附物连接图。
3. 区分锚定 C、甲基/亚甲基 C、羟基/醚 O。远离表面的原子即使投影落在 hollow，也不算 hollow 吸附；同一个最近 Fe 也不等于相同吸附模式。
4. 原目标的 ML 解离产物不能替代完整分子的位点覆盖。DFT 从完整起点迁移/解离则是有效的该起点计算证据，但不证明其他所有位点都不稳定。
5. 已有去重结论沿用各批次正式结构审核；本清单不重新授予稳定态、科学验收或登记状态。

本次几何审核包含57个原始候选、6个补充/修复候选、56个源哈希核验过的首次 DFT 输入、46个已收集 VASP 输入和46个缓存 DFT 输出，共211个**阶段记录**。它们不是211个独立吸附态；原始集合还含未提交、被阻断或后来替换的种子，缓存输出包含两个06_C配对对照。
