# Phase 3.1 单点动力学分析验收

从 Phase 3.0 已验收结果离线复现了合成 Ni/Cu 四步反应的覆盖度、方向通量、总周转和选择性。新增代码位于 baseline_mkm 模块。开发目录和独立发布工作树分别验证，发布分支保留了用户指定基线 ca13b069 之后的 NEB 测试维护提交 877e7f9a。

## 可执行入口和产物

`python -m scripts.baseline_mkm.analysis run RUN OUTPUT` 读取接受回执和冻结的输入。另有 `analyze` 读取可移植回执，`inspect` 检查草案。入口重建评审过的动力学数据，核对工单、研究问题、运行和模型版本、源文件摘要、收敛及审批状态。每个接受结果生成一份机器可读分析、一份分节的人读报告和一份 H7 手动交接数据。[调用方式与能力矩阵](../../../modules/baseline_mkm/README.md) · [JSON Schema](../../../configs/kinetics/mkm_analysis.schema.json)

## 合成基准

固定 400 K。H₂、NO、HNO 分压分别为 1、0.5、0.1 bar。基准定义一个参考位点对含一个 Ni 顶位和一个 Cu 桥位。归一化元数据绑定到原合成基准文件的 SHA-256。[归一化依据](benchmark_normalization.json)

| 局部库存 | 物种覆盖分数 | 空位分数 | 占位与空位余额 |
| --- | --- | ---: | ---: |
| Ni 顶位 | H 0.30710124，HNO 0.40121221 | 0.29168655 | 0 |
| Cu 桥位 | H 0.69667948 | 0.30332052 | 0 |

同一总反应 H₂ + 2 NO ⇌ 2 HNO 的周转为 **81.51277016 s⁻¹/参考位点对**，HNO 生成量为每位点对每秒 **163.02554032 个分子**。声明产物集合内 HNO 摩尔选择性为 **1**。基准不含碳，碳选择性为空。Ni 顶位以 HNO 占位最多；两个催化相的局部库存分别守恒。基准未提供绝对位点密度、装填量或流量，绝对表面浓度、按面积/质量/体积的速率及未转化进料均为空。[位点与物种路径图](closed_cycle/pathways.md) · [人读报告](closed_cycle/report.md) · [分析数据](closed_cycle/analysis.json)

四步的正逆系数、单位和通量分别保留。根据分压、吸附物覆盖及空位幂重建方向通量，并将有符号的基元净通量按物种化学计量求和。使用归一化文件中已列出的净通量计算，最大表面余额为 0；上游 Phase 3.0 用方向通量相减重建得到 5.68 × 10⁻¹⁴。H、N、O 净气相元素余额均为 0。吸附步的正向活化自由能为 0.4 eV，原生定温表观能垒为 0.78531683 eV。

每次总周转对应吸附、转移、加氢和脱附的**净事件数为 1、1、2、2**。吸附和转移涉及两个物相。由 H₂ 至 HNO 的物种图可经顶位直接进入加氢，也可经桥位转移后进入加氢。图同时保留全部共反应物、位点计量和方向。这些路径没有唯一贡献百分比，当前结果也没有速率控制步骤的判定。

本轮未启动 CATKINAS，原来的 MAT、日志摘录及归一化结果均通过原有文件哈希核验。真实归档运行目录和可移植回执分别生成同一分析 JSON，SHA-256 为 `76633f244d9a381f0fcfa458eb6f2ca6490337d9bfd78b295fedf82067524151`。单向分析器保留缺失的逆系数和逆通量；已验证的 CATKINAS 原生路线仍仅支持可逆模型。

新增测试覆盖 Ni/Cu 界面、氧化物酸碱位和合成 Fe 台阶/口袋位。C₁/C₂ 等摩尔合成产物的碳选择性分别为 1/3 和 2/3；负净生成量单列为消耗。独立的合成口径验证了不等位点权重、密度、面积、质量、体积换算及转换证据不一致时的拒绝。覆盖权重和物理换算描述给定稳态的报告口径；若位点密度影响模型本身，须另有相应模型的接受结果。

开发过程中，一项测试曾将基准中的可逆往返误作由不同基元步骤组成的闭合物种路径。现分别检查单步可逆性、物种互达性和不同反应组成的循环，并用含备选转移步骤的独立合成图验证后一种情形。路径搜索每对进料和产物最多给出 32 条简单路径，最多扩展 4096 次，输出标示截断。报告没有进行 DRC、连续流反应器求解、循环通量分解或参数扫描。

H7 交接数据复用原有工单及 question_id。对原隔离 Registry 的副本执行既有计划接口，得到向原 MKM 计算追加一个分析文件的计划，范围仅为 files。生产数据库写入为零，生产看板和待审提案没有自动更新。[工单交接数据](closed_cycle/ticket_handoff.json)

## 真实 Fe(110)

CH* + CO* → CHCO* 仅生成了草案结构图，反向边未获确认。列出的 11 项动力学缺口包括 IS/FS 热化学校正、催化相、电荷、占位与空位、可逆性和评审参数。覆盖度、TOF、选择性、位点利用率及反应通量继续为空。[草案路径图](fe110/pathways.md) · [缺项报告](fe110/report.md) · [结构图与显式缺失值](fe110/analysis.json)

下一项可执行工作是由研究者确认 Fe(110) 三个吸附物的占位集合、重数及两侧空位，再用已确认映射重做位点配平。
