# SBQ123 system architecture authority

[System overview](docs/architecture/SYSTEM_OVERVIEW.md) records the implemented scientific flow. [Module map](docs/architecture/MODULE_MAP.md) resolves those responsibilities to code. [Dependency graph](docs/architecture/DEPENDENCY_GRAPH.md) records actual import directions, process boundaries and limits of static analysis. [Data contracts](docs/architecture/DATA_CONTRACTS.md) define what crosses those boundaries.

Root ARCHITECTURE.md and FINAL_ARCHITECTURE.md describe earlier phases. docs/12_WORKFLOW_ARCHITECTURE.md describes the historical workflow design, and configs/skill_routing.yaml assigns workflow ownership. Historical phase design reports remain dated records. This index selects the current authority without rewriting those records.
