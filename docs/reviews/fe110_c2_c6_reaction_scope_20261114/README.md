## 覆盖矩阵

| 维度 | 必须区分的内容 |
|---|---|
| 碳骨架 | 体系总碳数、最大相连碳骨架、分离片段数；C3+C3共吸附不等于完整C6链 |
| 反应类型 | C–C形成/断裂、加氢/脱氢、H迁移、C–O变化；CO插入需单独核实原子映射与连接变化 |
| 化学结构 | 不同H/O分布、饱和/不饱和或自由基结构；正式化学身份来自审定来源，不以距离阈值单独证明键级 |
| 表面局域环境 | C/O/H–Fe结合、多点锚定、局部Fe变形，以及不同构象和邻近片段 |
| 路径位置 | 反应物、上坡、近鞍点、下坡、产物及偏离路径的优化结构；低力不自动等于稳定极小值 |
| 数据用途 | 训练反馈、开发、独立验收；按结构/反应家族隔离，避免相邻帧泄漏 |

C1、CO和H等可作为链增长或氢转移的反应构件保留。该说明没有扩大到其他金属、表面或新增元素；继续以当前Fe(110)/Fe–C–H–O研究分支为基础。

## 筛选次序

1. 优先盘点C2/C3/C4现有结构、已定位反应路径、E/F标签和来源；对C5与C6分别筛少量代表性来源。未找到的具体结构ID、路径和标签标记Needs confirmation，不虚构候选。
2. 先复用兼容的已有标签，再寻找“反应类型新增覆盖＋局域环境新增覆盖”的候选。对长轨迹去冗余，不依帧数代替反应多样性。
3. 对有DFT标签的相同坐标测量真实力失配；无标签候选使用结构新颖度和已获支持的预测诊断。单模型不产生委员会不确定性。
4. 选样同时重视优化交接失配和反应覆盖。不能只追求低力极小值而漏掉反应区，也不能只增加高力扰动而忽视低力/软模式误差。
5. 10–20个新增DFT单点仍为首轮预算提案，优先用于C2–C4主线缺口；C5/C6先复用已有合格标签，确有必要时提出少量反馈。来源与候选尚未确定前，不按碳数机械均分，不承诺这一轮完成广域覆盖。独立验证单点计入同一总额，未来完整路径/优化验收另报预算。
6. 在新增家族通过审核后，另建派生数据包并做相同初始化、相同预算的微调对照；重点检查C2/C3/C4路径与优化表现，同时单列C5/C6代表性结果。相对能量或势垒能力须按独立能量目标与TS验收协议验证。

候选矩阵首先包含链增长的相邻规模，例如C1+C2→C3、C1+C3→C4、C1+C4→C5、C1+C5→C6。其他偶联组合、断裂或含氧支路只有在化学合理且来源可审核时进入候选池。这些是待核实的反应类别，不是已定位路径、主导机理或已批准作业。
