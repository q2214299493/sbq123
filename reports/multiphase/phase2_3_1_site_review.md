## 请研究者填写的决定

可比较两种库存约定。若把两个长桥和两个 hollow 各定义为独立库存，并确认两个碳各占一个 hollow，则最小空位交换是正向消耗这两个 hollow 空位并释放两个长桥空位。若把所有中心并入同一种可互换库存，且两个反应物各占一份、产物只占一份，则只能由守恒推出净释放一份。共享 Fe 引起的互斥、独立库存或模型所需的额外空位，都需要单独依据。这些条件推演未写入真实网络的占位字段。

1. **位点清单和表面域。** 确认 Fe(110) 单表面，或给出修订域及依据。说明哪些中心属于同一类可占用的位点、哪些是独立库存，以及共享 Fe 是否导致互斥。若采用复合位点或按类型合并，请给出稳定 ID、类型、表面 ID 和几何定义。保留实际采用的条目。
2. **各物种占位。** 分别为 CH*、CO*、CHCO* 列出每个分子占用的位点 ID 和数量。以位点库存计数；参与配位的 Fe 原子数不能直接当作占位数。
3. **空位及方向。** 分别列出正向消耗、释放的各类空位。用 `{}` 表示已确认整侧为零，用 `{"位点ID": 0}` 表示明确核查过该位点为零，未知填 `null`。分类候选为 `association`，可改为有依据的类别，例如 `c_c_coupling`。可逆性填 `true`、`false` 或 `null`；若指定方向，请说明适用条件和来源。
4. **确认记录。** 复制下方 JSON 模板，在副本中修改 `mapping`，填写 `reviewer`、带时区的 `reviewed_at`、`reason`、`source_reference`，确认后将 `decision` 设为 `confirmed`。外部资料、用户提供的位点定义均可作为来源。原提案及其摘要用于绑定本次决定。可以只确认已有依据的部分。

收到决定后，构建器对各域内的每个库存分别检查“反应物占位 × 各自系数 + 消耗空位 = 产物占位 × 各自系数 + 释放空位”。仅在可逆性确认为真时生成交换两侧的逆反应。位点守恒通过后，当前案例的电荷及催化相正式记录仍需独立核实，才能升级结构等级。

本例的确认命令还需要 `--site-catalog reports/multiphase/phase2_3_1_fe110_site_types.json`。模板已绑定该文件的规范 JSON 摘要。文件列出 Fe(110) 的几何类型，允许的类型与已独立占用的库存分开记录。采用新的集合类型时，请在项目配置副本中定义该类型，按模块说明更新确认副本的 `site_catalog_sha256`。反应可逆性的进一步依据应标明温度、覆盖度或分压范围，并给出可比自由能或有来源的正逆机理、速率资料。
