`ΔF_i=||F_ML,i−F_DFT,i||`；向量RMSE为`sqrt(mean ΔF_i²)`，向量MAE为`mean ΔF_i`。分量MAE、按帧均值、按来源均值均另列，不混为同一指标。方向余弦仅统计两力范数均>1e-8的原子；接近零力时方向敏感，不能单凭平均余弦判定优化稳定性。
